## Architecture Patterns

- **Async-first:** Heavy use of `asyncio`, `asyncstdlib`, and async D-Bus (`dbus-next`)
- **Adapter Pattern:** Multiple VPN protocol adapters (Proton, Psiphon, WireGuard, Dummy)
- **Modular Packages:** Split into `libvpnmanager` (core library), `daemon` (service), `adapters` (protocol implementations)
- **Pydantic Models:** Strongly-typed data models for configuration, tunnel status, etc.
- **IPC Layer:** Multiple transport options (D-Bus, Unix sockets, WebSocket)
- **Linux Network Namespaces:** Using `pyroute2` for network isolation
