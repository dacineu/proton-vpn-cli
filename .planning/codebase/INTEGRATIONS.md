# External Integrations Analysis

## Communication Protocols

### D-Bus
- **Library:** `dbus-next` (async)
- **Purpose:** Inter-process communication (IPC) between daemon and clients
- **Components:**
  - `libvpnmanager/dbus/` - D-Bus service and client implementations
  - `libvpnmanager/adapters/unix_adapter_server.py` - Unix socket adapter server
- **Usage:** Primary IPC mechanism on Linux for local communication

### WebSocket
- **Library:** `websockets>=11.0`
- **Purpose:** Cross-platform IPC transport alternative
- **Component:** `libvpnmanager/ipc/websocket.py`
- **Usage:** Enables remote clients to connect when D-Bus is unavailable

### Unix Sockets
- **Implementation:** `libvpnmanager/ipc/unix_socket.py`
- **Purpose:** Local IPC fallback, lightweight alternative to D-Bus
- **Usage:** Adapter communication, daemon transport

## System Integration

- **Purpose:** Network namespace management, routing, interface configuration
- **Components:**

- **Capabilities:** Create/manage network namespaces, configure interfaces, routing tables
