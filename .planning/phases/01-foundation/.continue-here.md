<decisions_made>

- Per-request TOTP 2FA: No session tokens. Every CLI request carries fresh TOTP code. MTM holds TOTP secret encrypted; adapter gets in-memory copy at spawn.
- Socket paths: /run/mtm/adapters/{os_user}_{adapter_type}.sock for CLI, /run/mtm/control/{os_user}_{adapter_type}.sock for MTM→adapter control.
- Adapter token validation: Adapter only checks session_token (not separate cli_2fa_token) because MTM already verified TOTP before spawning.
- Credential handling: stdin transport, immediate zeroization after VPN login.
- Dummy adapter: full simulation, varying device names (dummy0, dummy1...), 500ms-1s delay, implements AllocateTunnel even if namespace creation mocked.
