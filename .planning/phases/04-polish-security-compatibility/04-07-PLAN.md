<action>
1. In each adapter's startup sequence, after reading the stdin payload into a variable (likely a dict or bytes), overwrite the raw input buffer if possible. If using `asyncio.StreamReader`, the data may be in an internal buffer; we cannot easily zero it. Instead, after parsing JSON, immediately overwrite any mutable bytearray that held the raw data.
   - If we read into a `bytearray`, we can zero it: `raw_buffer[:] = b'\x00' * len(raw_buffer)`.
   - For higher-level dict structures, we should also zero sensitive fields after use: `password`, `totp_secret` (from startup), and any copies.
2. After the adapter performs VPN login (successful), zero the credential fields:
   ```python
   def _zero_credentials(self):
       cred = self.credentials
       for key in ('password', 'username', 'totp_secret'):
           if key in cred and isinstance(cred[key], (bytes, bytearray, str)):
               if isinstance(cred[key], (bytes, bytearray)):
                   cred[key] = b'\x00' * len(cred[key])
               else:
                   cred[key] = '\x00' * len(cred[key])
   ```
   Call `_zero_credentials()` after login success and after any later re-authentications.
3. Add module-level comment explaining this satisfies SEC-02 (no credentials in /proc/environ and memory sanitation).
4. Note: We already avoid putting credentials in environment (passed via stdin). Also ensure we don't accidentally store credentials in logs.
</action>
